# Lumière Studio — салон красоты (лендинг)

Статический одностраничный сайт (лендинг) салона красоты Lumière Studio в Лучезарном. Свёрстан на чистом HTML/CSS/JS без сборки и зависимостей — оригинал экспортирован из Tilda.

## Структура проекта

```
ladya-beauty-salon/
├── index.html      # основная страница лендинга
├── example/        # исходный пример страницы (экспорт из Tilda)
├── assets/         # стили, скрипты, изображения и SVG-иконки
└── .gitignore
```

## Секции лендинга

- Hero («Красота в деталях»)
- О салоне
- Услуги и цены
- Мастера / команда
- Галерея
- Отзывы
- Контакты с картой и телефоном

## Запуск

Проект не требует сборки и установки зависимостей. Достаточно открыть `index.html` в браузере, либо поднять локальный сервер:

```bash
# Python
python -m http.server 8000
# или
npx serve .
```

Затем открыть http://localhost:8000
